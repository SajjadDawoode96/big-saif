# 23. Codex Strategy

Codex هو مساعد تنفيذ وليس المرجع الأساسي للمشروع.

القواعد:

1. لا نعطي Codex المشروع بالكامل دفعة واحدة.
2. كل مهمة تكون صغيرة ومحددة.
3. يتم شرح المهمة قبل إرسالها.
4. يتم فحص الملفات التي عدلها.
5. يتم تشغيل الموقع واختبار النتيجة.
6. بعد نجاح المرحلة يتم عمل Git commit.
7. يتم تحديث هذه الوثيقة عند الإنجازات المهمة.

إذا توقف Codex أو انتهت حصته:

يمكن متابعة المشروع يدوياً باستخدام VS Code وChatGPT.

المشروع لا يعتمد على Codex للاستمرار.
